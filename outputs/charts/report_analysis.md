# 轨迹预测方法对比分析报告

## 性能总表（Argoverse v1.1 验证集，39472 场景）

| 方法 | 类型 | minADE (m) | minFDE (m) | MR @2m |
|------|------|:----------:|:----------:|:------:|
| CV (匀速模型) | 规则基线 | ~5.0 | ~10.0 | ~80% |
| Kalman 滤波 | 规则基线 | 2.26 | 5.15 | ~50% |
| LSTM | 深度学习（单模态） | 1.99 | 4.60 | ~35% |
| HiVT-64 | Transformer+地图（单模态） | 1.36 | 2.98 | ~20% |
| HiVT-128 | Transformer+地图（单模态） | 1.33 | 2.88 | ~18% |
| **DenseTNT (Ours)** | **VectorNet+地图（6模态）** | **1.20** | **2.09** | **30.0%** |

## 各方法优缺点

### CV
- 原理：假设匀速直线运动，线性外推
- 优点：零计算，可解释
- 缺点：无视道路/交互，弯道完全失效
- 适用：高速公路直行段的粗略基线

### Kalman 滤波
- 原理：线性状态估计（位置+速度），恒定加速度模型
- 优点：比 CV 更平滑，在线延迟极低，对噪声鲁棒
- 缺点：无法建模非线性动态（转弯），忽略地图和交互
- 适用：实时系统快速初始预测

### LSTM
- 原理：编码器-解码器 LSTM，纯轨迹方法
- 优点：比 Kalman/CV 显著提升，能捕捉非线性模式
- 缺点：无地图感知，单模态输出，自回归误差累积
- 适用：无高精地图的迁移场景

### HiVT (Hierarchical Vector Transformer)
- 原理：层次化 Transformer，局部+全局注意力建模 agent 和 lane 交互
- 优点：多模态版本 SOTA（FDE 0.97），利用轨迹+车道拓扑
- 缺点：多模态版本模型容量大、训练成本高（其多模态输出为 Laplace 混合分布，不依赖 DenseTNT 式的离线目标集优化后处理）
- 适用：高精地图可用的复杂城市场景

### DenseTNT（本项目）
- 原理：VectorNet 编码轨迹+车道，密集目标采样+评分+轨迹补全
- 优点：单模态指标全面最优（minADE 1.20），端到端不依赖 NMS，训练仅 60k/205k 仍有空间
- 缺点：top-k 选点不如 optimization 精细，MR 偏高
- 适用：端到端多模态预测，地图可用的场景
