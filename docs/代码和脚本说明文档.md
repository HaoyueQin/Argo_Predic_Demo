## DenseTNT 训练代码（仓库根）

DenseTNT 代码位于仓库根目录（上游 [Tsinghua-MARS-Lab/DenseTNT](https://github.com/Tsinghua-MARS-Lab/DenseTNT) main 分支 + 本项目改造），
`src/` 为训练核心代码。

### 训练/评估工具（仓库根）

#### train_v4.py（src/）

**功能**: 最终训练入口。单次 DDP 启动、epoch 循环在 Python 内完成，支持：
- 跨 epoch 保留 optimizer 状态（论文 LR 策略：每 5 epoch 衰减为 30%）
- 每 epoch 自动验证（minADE / minFDE / MR）+ patience 早停
- `--resume` 断点续训（checkpoint.pt）
- 验证缓存由主进程预构建（避免 mp.spawn 内 fork Pool 的已知问题）

**运行环境**: WSL + DenseTNT 训练环境

**运行命令**:
```bash
python src/train_v4.py     --do_train     --data_dir train/data     --data_dir_for_val val/data     --output_dir model_save_full_chunked     --train_batch_size 64     --eval_batch_size 64     --hidden_size 128     --future_frame_num 30     --num_train_epochs 16     --patience 5     --checkpoint_interval 100     --learning_rate 0.001     --core_num 4     --num_workers 0     --distributed_training 1     --use_map --use_centerline --argoverse     --other_params semantic_lane direction l1_loss goals_2D                    enhance_global_graph subdivide goal_scoring                    laneGCN point_sub_graph lane_scoring                    complete_traj complete_traj-3
```

**恢复训练**: 在命令末尾加 `--resume`。

#### eval_all_models.py

**功能**: 批量评估 `model_save_full_chunked/model_save/` 下全部 epoch 模型，输出汇总到 `val_results_all.txt`。

**运行命令**:
```bash
python eval_all_models.py [--data_dir val/data] [--output_dir model_save_full_chunked]
```

#### eval_single.py

**功能**: 单独评估一个 epoch 模型。

**运行命令**:
```bash
python eval_single.py 15            # 评估 model.16.bin（epoch 从 0 开始）
python eval_single.py --model-path /path/to/model.10.bin
```

#### dashboard.py

**功能**: 训练监控 Web 面板（`http://localhost:8080`），实时显示 GPU/CPU/内存、训练进度、loss 曲线、验证历史、看门狗重启次数。

**运行命令**:
```bash
python dashboard.py [--port 8080]
# 训练日志需重定向到 model_save_full_chunked/training.log：
# python src/train_v4.py ... 2>&1 | tee model_save_full_chunked/training.log
```

#### watchdog.sh

**功能**: 训练看门狗，训练进程崩溃后自动重启（指数退避，默认最多 10 次）。

**运行命令**:
```bash
bash watchdog.sh "python src/train_v4.py --do_train ..." [log_file] [max_retries]
```

#### mk50k.sh

**功能**: 从训练数据创建 N 条样本的子集（symlink），用于快速实验。

**运行命令**:
```bash
bash mk50k.sh train/data train/data_50k 50000
```

### src/ 目录（DenseTNT 核心）

| 文件 | 说明 |
|------|------|
| `src/train_v4.py` | **当前训练脚本**（见上） |
| `src/run.py` | 上游 run.py + 改造（--resume 断点续训、取消 batch_size 断言） |
| `src/dataset_argoverse.py` | 上游数据集类 + 改造（Queue → Pool 防死锁） |
| `src/dataset_argoverse_chunked.py` | 分块磁盘缓存数据集（205k 数据不全量进内存） |
| `src/do_eval.py` | 评估入口（单模型，内存版数据集） |
| `src/modeling/` | VectorNet 模型（vectornet.py / decoder.py / lib.py） |
| `src/utils.py` | 工具函数（含 --resume 参数、禁用 input 阻塞） |
| `src/structs.py` | 数据结构 |
| `src/setup.py` | Cython 扩展编译 |
| `src/utils_cython.pyx` | Cython 加速源码 |

**Cython 编译**（首次运行前执行一次）:
```bash
cd src && cython -a utils_cython.pyx && python setup.py build_ext --inplace && cd ..
```

## 环境说明

### 通用环境 (.venv)

用于基础功能：数据预处理、可视化、评估等。

```bash
# 创建环境
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# 或
.venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt
```

### DenseTNT 训练环境 (.venv_densetnt)

用于 DenseTNT 模型训练和评估，需要 GPU 支持。

```bash
# 在 WSL 中创建环境
python3 -m venv .venv_densetnt
source .venv_densetnt/bin/activate

# 安装依赖
pip install -r requirements_densetnt.txt
```

## 注意事项

1. **WSL 路径**: 所有 WSL 脚本中的路径都使用 `<project_root>/` 格式
2. **Windows 路径**: 在 Windows 下运行时请将路径替换为你的实际项目路径
3. **相对路径**: 部分脚本支持相对路径，建议在项目根目录下运行
4. **GPU 要求**: DenseTNT 训练需要 NVIDIA GPU 和 CUDA 支持
