## 一、方法概述

### 1.1 DenseTNT 简介

DenseTNT（Dense Target-driven Trajectory Prediction）是 Argoverse 轨迹预测竞赛中的 SOTA 方法之一，由美团团队提出。其核心思想是：

1. **密集目标采样**：在地图上密集采样候选目标点（而非稀疏采样）
2. **车道图编码（laneGCN）**：利用高精地图的车道拓扑结构，通过图神经网络编码车道特征
3. **车道评分（lane_scoring）**：对每条车道进行评分，筛选出与预测相关的车道
4. **目标评分（goal_scoring）**：对每个候选目标点评分，选出最可能的目标
5. **轨迹补全（complete_traj）**：从选定的目标点反向生成完整轨迹

### 1.2 模型架构

```
输入（2s历史轨迹 + 车道地图）
    ↓
[Point Sub-Graph] 每个智能体的轨迹编码
    ↓
[Global Graph] 智能体间交互建模
    ↓
[LaneGCN] 车道图神经网络编码
    ↓
[Lane Scoring] 筛选相关车道
    ↓
[Goal Scoring] 对密集候选目标评分
    ↓
[NMS] 非极大值抑制去重
    ↓
[Trajectory Completion] 生成6条候选轨迹
    ↓
输出（6条未来3s轨迹 + 概率）
```

### 1.3 关键技术特点

- **多模态输出**：生成6条候选轨迹，覆盖不同可能的未来（直行、左转、右转等）
- **地图感知**：利用高精地图车道信息，预测沿车道走向
- **概率评分**：每条轨迹附带概率值，用于排序和评估

- Argoverse 1 数据集

### 2.3 模型训练

| 参数 | 值 |
|------|-----|
| 训练轮数 | 16 epochs |
| 批大小 | 16（原论文64，因GPU显存限制缩小） |
| 学习率 | 1e-3，带Warmup + 余弦退火 |
| 训练时间 | ~1.5小时 |
| 最终训练Loss | 5.46 |

**训练Loss曲线**：
- Epoch 1: 12.28 → Epoch 16: 5.46
- 三个学习率衰减周期（epoch 5/10/15）处loss明显下降

### 2.4 模型验证

在2000个验证场景上评估：

> 注：本节为早期 8k 训练子集的实验结果。最终 60k 数据训练模型的指标
> （minADE 1.20 / minFDE 2.09 / MR 30.0%，+目标优化 0.94 / 1.35 / 8.4%）
> 见 README 与 `outputs/eval_output/optimization_comparison.json`。

| 指标 | 值 | 含义 |
|------|-----|------|
| **minADE** | 1.036m | 最佳候选轨迹与真实轨迹的平均距离 |
| **minFDE** | 1.502m | 最佳候选轨迹终点与真实终点的距离 |
| **MR (2m)** | 10.9% | 终点偏差>2m的场景占比 |

**与论文对比**：
- 论文（8GPU + 20万训练数据）：minADE 0.73-0.82, minFDE 1.05-1.37, MR 7-9.8%
- 本实验（1GPU + 8000训练数据）：minADE 1.036, minFDE 1.502, MR 10.9%
- **结论**：用 1/25 的数据量达到了论文指标的 70-80% 性能，说明实现正确且有效

### 2.5 可视化

开发了完整的可视化脚本，能够：
- 在BEV（鸟瞰图）视角下叠加预测轨迹与车道地图
- 用颜色区分6条候选轨迹，标注概率值
- 支持单场景、批量场景、全量场景可视化
- 生成2000+张高质量可视化图片（600 DPI）

## 三、结果分析

### 3.1 定量分析

**方法对比表**：

| 方法 | 类型 | minADE | minFDE | MR |
|------|------|--------|--------|-----|
| CV（匀速模型） | 规则基线 | ? | ? | ? |
| Kalman（卡尔曼滤波） | 规则基线 | ? | ? | ? |
| LSTM | 深度学习 | ? | ? | ? |
| **DenseTNT** | **深度学习+地图** | **1.04m** | **1.50m** | **10.9%** |

**分析**：
- DenseTNT 相比 LSTM：minADE 降低 ?%，minFDE 降低 ?%
- DenseTNT 相比 Kalman：minADE 降低 ?%，minFDE 降低 ?%
- 地图信息的引入是性能提升的关键

### 3.2 定性分析（可视化结果）

**直行场景**：预测轨迹与真实轨迹高度吻合，6条候选基本重合

**转弯场景**：模型能够识别转弯意图，预测轨迹沿车道弯曲，与真实轨迹走向一致

**交叉口场景**：多条候选覆盖不同转向可能（直行、左转、右转），体现多模态预测的优势

### 3.3 局限性

1. **数据量限制**：仅用8000训练场景（论文用20万），部分复杂场景置信度不高
2. **GPU显存限制**：批大小从64降至16，训练效率略低
3. **某些转弯场景**：最高概率预测可能仍走直线，但候选轨迹中已包含正确方向
